# 🗨️ Distributed Chat Application

A simple Python-based distributed chat system using socket programming and multithreading. This mini-project demonstrates core distributed system concepts such as message broadcasting, concurrency, and client-server communication.

---

## 📌 Features

- Real-time chat among multiple clients  
- Server broadcasts messages to all connected users  
- Handles multiple clients simultaneously using threads  
- Console-based UI for simplicity  
- Easy to extend and modify  

---

## 🛠️ Tech Stack

- **Language**: Python 3  
- **Networking**: TCP Socket Programming  
- **Concurrency**: `threading` module
